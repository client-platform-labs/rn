## 1. 目的

本入口为实施与运维的**导航与编排**：指引各角色完成「宿主发布 → 签名热更新 → 日常变更与回滚」最小闭环，并在故障时快速定位到操作手册。

架构说明、命令/API 事实表、生产事故处置分别收录于架构手册、参考手册、操作手册；本入口不重复其正文。

## 3. 实施闭环（概览）

```text
业务可见变更
  → 宿主 release 安装并连通控制面
  → 控制面可验签（CRL / check / 制品）
  → 签名 JS 热更新在真机生效且进程稳定
  → 日常再发布 / 包级回滚
  → 故障时按操作手册紧急通道处置
```

| 场景 | 文档 |
|------|------|
| 首次从零完成闭环 | [实施引导](./get-started.md) |
| 钢线已通后的再发布 / 回滚 | [日常运维](./daily.md) |
| 灰度、容灾、吊销、开发环等 | [进阶主题](./deepen/index.md) |
| 生产故障定位 | [操作手册 · 紧急通道](./operations/index.md#0-紧急通道出事先看哪) |

## 5. 范围与对外口径

### 5.1 本版覆盖

- 绿地工程、Android 宿主、单业务模块（`main`）签名热更新  
- 日常再发布与包级回滚  
- 故障时指向操作手册紧急通道  

### 5.2 本版不展开（见进阶主题或后续专册）

灰度放量、SLO / quality gate、密钥吊销演练、DR 冷重建、棕地（Brownfield）、iOS / HarmonyOS、AB 实验、应用商店提审。

### 5.3 对外宣称

| 允许宣称 | 条件 |
|----------|------|
| 单 module 可企业推广（L4） | 按实施引导完成验收关闭（阶段 E） |
| 企业闭环（L5） | 须满足推广门禁 L5 证据；**不得**在钢线未关闭时宣称 |

推广门禁层级定义见仓库 `docs/agents/enterprise-promotion-gates.md`。
