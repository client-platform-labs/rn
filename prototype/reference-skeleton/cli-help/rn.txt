Usage: rn <command> [options]

Local / diagnostic host. Optional family umbrella: `client-platform rn …`
(same plugin surface; not required for the happy path).

Commands:
  init              Scaffold workspace (default targets: ios, android)
  add-target        Add a runtime target plugin (e.g. harmonyos) — hot-plug
  doctor            Detect drift; safe autofix only
  doctor --report   Redacted diagnostic package
  diag collect      Alias for diagnostic package
  dev               Metro + device discovery
  generate          Templates / codegen (--dry-run)
  capability        List / probe / add capability plugins
  plugin list|info  Discovered plugins (package.json#clientPlatform)
  migrate           schemaVersion migrations
  config show|validate

Global:
  --non-interactive   (implied by CI=1)
  --json              machine on stdout; humans on stderr
  --help

Exit: 0 ok | 1 fail | 2 usage | 3 gate/compat | 4 creds | 5 network

Config: flags > env > project JSONC (schemaVersion) > defaults
Plugins: install npm package → register via clientPlatform → lazy import()
